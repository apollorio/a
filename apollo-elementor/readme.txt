Server-rendered Elementor widgets with cache-first data helpers for the Apollo ecosystem.

== Description ==

Premium Elementor widgets for DJ profiles, event pages, weekly planners, monthly calendars, charts dashboards, and gestor management views. All widgets are server-rendered with cache-first architecture and JS hydration only for interactivity.
