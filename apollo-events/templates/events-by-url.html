Importador de Eventos / Shotgun + BlueTicket

Cola a URL do evento. O importador detecta a plataforma, busca o HTML, extrai os campos mapeados para o CPT event e só libera o envio quando todas as luzes ficarem verdes.

Configuração de conexão

O navegador não consegue buscar HTML de shotgun.live / blueticket.com.br diretamente (CORS bloqueia o fetch cross-origin — nenhum dos dois envia cabeçalho Access-Control-Allow-Origin). Duas saídas: (1) configurar um endpoint no WP que faça o wp_remote_get() por você e devolva o HTML bruto, ou (2) colar o HTML manualmente quando pedido — abra a página do evento, "Exibir código-fonte" (Ctrl+U), copie tudo e cole aqui.
